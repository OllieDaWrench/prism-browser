Get Prism on this computer

Prism runs on your own computer, so it can drive the Chrome, Edge or Chromium already there — that is what makes Live mode, and Cloudflare-protected sites, work.

macOS — recommended: one command, no "cannot be verified" warning

Paste this into Terminal (Spotlight → Terminal). It installs Prism to ~/Prism, puts a launcher on your Desktop, and never asks for an administrator password.

curl -fsSL /install.sh | bash

Or download the zip

Prism-macOS.zip Prism-Windows.zip

Unzip, then double-click Open Prism.command (Mac: right-click → Open the first time) or Open Prism.bat. The first start unpacks Prism's own Node.js into that same folder. Delete the folder to remove Prism.
