Prism

Prism runs as a local server

Opening Prism.html straight from disk cannot work: a browser page loaded from file:// is not allowed to fetch other websites, so Prism has nothing it can proxy through.

Start the server, then use it at http://localhost:3000:

npm start

On Windows you can just double-click Open Prism.bat, which starts the server for you.

Open Prism

If the button does nothing, the server is not running yet.
